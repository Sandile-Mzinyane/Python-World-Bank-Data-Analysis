#  Python Data Analysis Project

## Education Attainment and Economic Growth in South Africa

This project analyses the relationship between **education attainment** and **economic growth in South Africa from 2010–2020**, using data from the **World Bank Education Statistics** and **World Development Indicators (WDI)**.

##  Project Objective

The objective of this project is to demonstrate a complete data analysis workflow, including:

- Data preparation and cleaning
- Numerical analysis
- Data visualisation
- Database integration
- Data transformation
- Interpretation of findings

##  Datasets

### Education Statistics
- **Indicator:** Percentage of the population aged 25+ whose highest level of education is a Bachelor's degree or equivalent
- **Country:** South Africa
- **Period:** 2010–2020

### World Development Indicators
- **Indicator:** GDP growth (annual %)
- **Country:** South Africa
- **Period:** 2010–2020

##  Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQLite

##  Analysis Performed

The project includes:

1. **Data Preparation**
   - Imported and cleaned the datasets
   - Selected relevant indicators
   - Handled missing values
   - Restricted the analysis to the common period of 2010–2020

2. **Numerical Analysis**
   - Converted data into NumPy arrays
   - Reshaped arrays
   - Calculated descriptive statistics
   - Performed correlation analysis

3. **Data Visualisation**
   - Created trend visualisations
   - Created scatter plots
   - Examined the relationship between education attainment and GDP growth

4. **Database Integration**
   - Stored the analysed data in SQLite
   - Performed SQL queries
   - Demonstrated database operations
   - Loaded database results into Pandas

5. **Data Analysis**
   - Performed data transformations
   - Used tables and visualisations to identify patterns
   - Interpreted the results

##  Key Finding

The analysis indicates a **slight positive association** between Bachelor's-level education attainment and GDP growth during the 2010–2020 period. However, the relationship is relatively weak, suggesting that education attainment alone does not fully explain changes in South Africa's economic growth.
